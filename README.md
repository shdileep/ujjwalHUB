# Ujjwal Hub - Municipal Waste Management Platform

Ujjwal Hub is a state-of-the-art municipal infrastructure and fleet management system designed to optimize sanitation operations through real-time data, spatial intelligence, and AI integration.

## 🚀 Key Features

### Driver Dashboard
- **Ujjwal Route**: Sequential, ID-based collection path optimizing the collection workflow.
- **Double-Tap Tasking**: Deliberate interaction for bin collection to prevent accidental status changes.
- **AI-Powered Leave Applications**: Integrated Gemini AI to professionalize communication for government records.
- **Live Duty Pulse**: Real-time session tracking for accurate payroll and auditing.

### Admin Dashboard
- **Mission Control**: Live Online/Offline status tracking of the entire fleet.
- **Performance Dossiers**: Automatically generated, printable professional audits for field personnel.
- **Lifecycle Analytics**: PDF reports of duty timestamps and bin collection logs.
- **Hierarchical Area Governance**: Specialized ward filtering for zonal administrative oversight.

## 🧠 Intelligence & Algorithms
- **K-Means Spatial Clustering (K=2)**: Automatically partitions wards between drivers to eliminate route overlap.
- **Route Optimization**: Implements **TSP**, **A***, and **Dijkstra** principles for sequential bin connections.
- **NLP (Natural Language Processing)**: Uses **Gemini 1.5 Flash** for professional tone correction and administrative grammar refinement.
- **PWA (Progressive Web App)**: Fully mobile-ready with an optimized manifest and 512x512 adaptive iconography.

## 🛠️ Technical Stack
- **Frontend**: React 18, Vite, Tailwind CSS, Framer Motion.
- **Backend/Realtime**: Firebase Real-time Database & Auth.
- **Intelligence**: Google Generative AI (Gemini).
- **Mapping**: Leaflet.js with custom municipal tile layers.

## 📦 Deployment
This project is configured for seamless deployment on **Vercel** or **Netlify** and is PWA-ready for direct installation on Android and iOS devices.
